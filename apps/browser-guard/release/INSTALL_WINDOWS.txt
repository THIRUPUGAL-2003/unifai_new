UnifAI Guard Windows install (v1.1.9)
===================================
1. Close previous UnifAI Guard if running (taskkill /im UnifAI_Guard.exe /f).
2. Prefer UnifAI_Guard.exe from this ZIP (must match VERSION.txt = 1.1.9).
3. Open http://127.0.0.1:18085/ — version must show 1.1.9, proxy_port OK.
4. Guard Agents UI → Active row must show Version 1.1.9 (not 1.6.0).
5. Fully quit Chrome/Edge (all windows) and reopen.
6. Test Target Website + multi-file upload + text Send (expect: filename -- text).

TURN OFF / UNINSTALL
--------------------
Windows Settings → Apps → UnifAI Guard → Uninstall
(or Start Menu → UnifAI Guard → Uninstall)

When prompted, enter the company uninstall key from Browser AI → Setup.
(Same key is used on macOS — see UNINSTALL_MACOS.txt.)

Notes:
- If UnifAI_Guard_Setup.exe is older than UnifAI_Guard.exe / VERSION.txt, ignore Setup — use the EXE.
- Website Download ZIP must be rebuilt/deployed on the server after each agent rebuild.
