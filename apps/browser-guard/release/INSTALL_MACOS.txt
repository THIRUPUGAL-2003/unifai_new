UnifAI Guard macOS install (v1.1.9)
===================================

PREFERRED (production): install the signed .pkg if IT provided UnifAI_Guard_*.pkg
  — double-click the .pkg, follow prompts, allow Keychain if asked.

ZIP / pilot path:
1. System Settings → Network → VPN & Filters → Filters.
   Remove or disable old UnifAI or third-party web content filters if conflicting.
2. Unzip UnifAI_Guard_macOS.zip (must match VERSION.txt = 1.1.9).
3. Open Terminal in the unzipped folder.
4. Run:
   chmod +x Install_UnifAI_Guard.command Uninstall_UnifAI_Guard.command
   ./Install_UnifAI_Guard.command
   (If unsigned Gatekeeper warning: System Settings → Privacy & Security → Open Anyway)
5. Open http://127.0.0.1:18085/ — version must show 1.1.9, proxy_port OK, ca trusted.
6. Guard Agents UI → Active row must show Version 1.1.9.
7. Fully quit browsers (Cmd+Q) and reopen: Safari, Chrome, Edge, Brave, Firefox.
   Safari: turn OFF iCloud Private Relay (or MDM enforces it).
8. Test Target Website + Send → confirm Prompt Logs (filename -- text).


If health shows proxy_port FAIL: quit Guard, reopen /Applications/UnifAI_Guard.app, wait 10s, refresh health.

TURN OFF / UNINSTALL
--------------------
See UNINSTALL_MACOS.txt (same company uninstall key as Windows).
Quick path: double-click Uninstall_UnifAI_Guard.command

Notes:
- Build on a Mac: installer/build_macos.sh → release/UnifAI_Guard_macOS.zip
- Production sign: installer/sign_and_notarize_macos.sh (Apple Developer ID required)
- Package: installer/build_pkg_macos.sh → release/UnifAI_Guard_VERSION.pkg
- AI Guard Bot (LLM) needs reachable Ollama on UnifAI server (BROWSER_AI_OLLAMA_URL). Regex works without Ollama.
