## Overview

UnifAI fetches its pricing and model parameter datasheets from `https://getunifai.ai/datasheet` on startup and periodically in the background. In environments without outbound internet access, these fetches fail and UnifAI cannot start.

Both fields accept `file://` URLs so you can load the datasheets from the local filesystem instead.

---

## Setup

**1. Download the datasheets** on a machine with internet access:

```bash
curl -o pricing.json https://getunifai.ai/datasheet
curl -o model-parameters.json https://getunifai.ai/datasheet/model-parameters
```

Transfer the files to your air-gapped host (or bake them into your container image / Kubernetes volume).

**2. Point UnifAI at the local files** in `config.json`:

```json
{
  "framework": {
    "pricing": {
      "pricing_url": "file:///opt/unifai/pricing.json",
      "model_parameters_url": "file:///opt/unifai/model-parameters.json",
      "pricing_sync_interval": 86400
    }
  }
}
```

<Note>
`file://` URLs require three slashes followed by an absolute path.
</Note>

**3. Ensure the files are accessible** to the UnifAI process at the configured paths before starting.

---

## Keeping datasheets current

UnifAI re-reads the file on every sync tick (`pricing_sync_interval`, minimum 3600 s).
